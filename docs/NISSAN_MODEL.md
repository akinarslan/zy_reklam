MeshoptSimplifier (Three.js dağıtımı), büyük primitive başına hedef %35 / hata .0015 / LockBorder: 232.295 üçgen. Vertex'ler kullanılan index kümesine göre sıkıştırıldı. Materyaller, ışık, kaplama ve atıf src/showcase/vehicle.ts / index.html içindedir. Kaplama fotoğrafın birebir texture'sı değildir.

Model ilk sayfa yükünde istenmez; kullanıcı 360° düğmesine bastığında yüklenir. Fiziksel mobil FPS kabulü yapılmadı.
